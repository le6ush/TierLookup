# TierLookup

TierLookup — клиентский Fabric-мод для Minecraft 1.21.11, который показывает PvP-тиры игроков без установки чего-либо на сервер.

Мод объединяет быстрый RAM-кэш, локальную SQLite-базу, интернет-поиск, сортируемый TAB, динамические таблицы, поиск игроков, сравнение, избранное и заметки.

[English README](README.md)

## Возможности

- **Тиры игроков в TAB** — режимы Legacy и Custom, сортировка по тиру, настройка масштаба и предпочитаемого кита.
- **Интерактивный Custom TAB** — можно заморозить список, навести курсор на игрока и открыть быстрые действия.
- **Динамические таблицы** — компактная информация о тирах игрока, на которого вы смотрите. Рендер читает только RAM.
- **Поиск на `K`** — недавние игроки, избранное и поиск по нику прямо в игре.
- **Сравнение игроков** — сравнение сохранённых тиров выбранным методом.
- **Заметки** — локальные заметки об игроках, сохранённые в базе TierLookup.
- **Интернет и Оффлайн** — RAM всегда проверяется первым; Интернет может обращаться к тирлистам, Оффлайн работает только с локальными данными.
- **Синхронизация локальной базы** — выбранные тирлисты можно загрузить в SQLite из настроек.
- **Точные значения рангов** — LT, MT и HT сохраняются такими, какими их отдаёт источник. Retired показывается только при явной отметке источника.
- **Только клиент** — серверная часть не нужна, runtime Mixin-инъекций нет.

## Поддерживаемые источники

- MCTiers
- PvPTiers
- SubTiers
- FlowPVP
- CISTiers
- ATiers
- MyTiers
- Central Tier List

Полнота данных зависит от того, что конкретный тирлист публикует наружу. TierLookup различает полную, частичную и неудачную синхронизацию, поэтому неполная загрузка не должна молча уничтожать более качественную локальную базу.

## Требования

- Minecraft Java Edition **1.21.11**
- Java **21**
- Fabric Loader
- Fabric API
- Mod Menu необязателен, но удобен для настроек

## Установка

1. Установите Fabric Loader для Minecraft 1.21.11.
2. Установите Fabric API.
3. Поместите JAR TierLookup в папку `mods`.
4. При желании установите Mod Menu.
5. Запустите Minecraft и настройте TierLookup через Mod Menu.

Стандартная клавиша TierLookup — `K`. Она меняется в обычном меню управления Minecraft.

## Данные и сеть

Кэш, избранное, алиасы, заметки и информация о локальной базе хранятся в папке Minecraft. Интернет-запросы выполняются только к выбранным публичным тирлистам и только когда выбранный режим подгрузки разрешает сеть.

Динамическая таблица не выполняет HTTP- или SQLite-запросы во время рендера.

## Сборка

Проект использует Java 21 и Fabric Loom.

```bash
gradle clean build
```

Готовый JAR появится в `build/libs/`.
