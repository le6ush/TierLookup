# Contributing

Bug reports and focused pull requests are welcome.

Before opening a pull request:

1. Build the project with Java 21.
2. Keep network and SQLite access out of the hover render path.
3. Preserve exact source tiers and source-explicit Retired semantics.

Please keep pull requests small enough to review and describe the user-facing reason for the change.

By submitting a contribution, you confirm that you have the right to submit it and allow it to be distributed as part of TierLookup under the repository's current license.
